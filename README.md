# Dead Current: The Last Shimmer

**Terminal Wave Defense** — суровый физический экшен, где каждый выстрел рвет землю на части.

Мир мертв, задохнувшись в радиоактивном смоге. Вы — оператор последнего квантового маяка, сдерживающего натиск безликих армий в реакторной зоне. Никаких стен. Никаких баррикад. Только чистая физика и нарастающая энтропия.

Ваше оружие — кинетика. Оттягивайте заряд и запускайте во тьму нестабильную плазму, чтобы не допустить Core Breach. Отвоевывайте пустошь: на дне кратеров от мощных попаданий зарождается Craterborn-аванпост. Разрастаясь, этот город питает маяк, повышая огневую мощь и выживаемость базы.

Днем вы копите энергию, но ночью тьма делает чудовищ вдвое сильнее. Выжигайте их тесла-катушками и модифицированными снарядами. И когда генераторы щитов падут под натиском черных джаггернаутов, вашей последней надеждой станет Singularity Core — опасная технология, но, увы, единственная, способная на мгновение отсрочить неизбежную пустоту.

**Жанры:** Smogcore, Terminal Wave Defense, Physics-based Action, Survival Arcade, Base Building.
